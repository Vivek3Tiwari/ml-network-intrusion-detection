# ML-based Network Intrusion Detection System

Machine-learning NIDS trained on the CICIDS2017 dataset to classify
network flows as benign or malicious (brute force, DoS, and more).

## Status
🚧 In progress

## Dataset
CICIDS2017 (Canadian Institute for Cybersecurity, UNB). Not included
in this repo due to size.

## Planned
- Data cleaning and EDA
- Random Forest / XGBoost classifiers
- Evaluation: precision, recall, macro-F1, false-positive rate
- Live-capture / PCAP-replay demo with dashboard
